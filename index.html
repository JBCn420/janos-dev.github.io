Farm Empire Tycoon — Rendszerarchitektúra

A Farm Empire Tycoon egy React + TypeScript alapon épült, valós idejű inkrementális stratógiai játék, komplex háttérmotorral, offline haladással és Supabase felhőalapú ranglistával.

🛠️ Technológiai Stakk

Frontend Core

React 18+, TypeScript, Vite, Tailwind CSS v4, Framer Motion animációk.

Állapotkezelés & Adatok

React Context API + Reducer, localStorage automatikus szinkronizáció.

Kereskedelem & Backend

Supabase REST API (Leaderboard & Stats), Recharts élő árfolyamgörbék.

🌾 Főbb Játékszabályok és Rendszerek

Parcellák és Talajápolás

Állapotgép: idle ➔ plowing ➔ plowed ➔ seeding ➔ growing ➔ ready ➔ harvesting. A talajminőség hat a hozamra; szerves és műtrágyázással 100%-ra állítható.

Géppark és Kopásmodell

Traktorok, munkagépek és kombájnok. A kopás műveletenként: 1.0% + (ha × 0.15%) (max 15% plafon). A teljes felújítás az újkori ár 30%-a.

Supervisor Automatizáció

Tömeges műveletirányítás: Tömeges szántás, Tömeges betakarítás, valamint Tömeges vetés növényválasztó drop-down menüvel (handleBulkSow).

Gyártás & Offline Haladás

Többlépcsős feldolgozóüzemek (Malom, Pékség, Biogáz, Fast Food). Újrainduláskor kiszámítja a távollét alatt lezajlott gyári ciklusokat.

🧮 Kiemelt Matematikai Képletek

1. Hozamszámítás (Calculate Yield)

Yield = BaseYieldPerHa × Area × (0.7 + SoilQuality × 0.003) × FertilizerBonus × CountryBonus × ResearchMult

2. Szervizköltség (Repair Cost)

RepairCost = (PurchasePrice × 0.3) × ((100 - CurrentCondition) / 100)

🎧 Hangmotor és Felhő Integráció

• SFX Audio Engine: Globális memóriacache-elt hangeffekt rendszer automatikus fallback útvonal-kezeléssel.
• Live Market & Contracts: 3 óránként frissülő vállalati megbízások, büntetőösszeggel és XP jutalommal.
• Global Leaderboard: Szinkronizált Supabase ranglista reakcióidő- és XP-követéssel.
